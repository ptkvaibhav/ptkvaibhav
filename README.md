## About me

I work on the **Product Security Incident Response Team (PSIRT)** at Guidewire, after nearly seven years of application security at Deloitte. Day to day that means:

- **Incident response** — triaging production security incidents, validating exploit reachability, and coordinating fixes across teams.
- **Secret governance** — running the TruffleHog leaked-secret response program end to end.
- **AppSec engineering** — correlating SAST, DAST and SCA results so teams only see findings that are real.
- **Offensive testing** — manual web and API penetration testing, business-logic and auth flaws.
- **AI security automation** — Claude AI skills and agents that take the repetitive parts out of vulnerability triage.
